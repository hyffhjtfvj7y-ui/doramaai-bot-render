📋 O QUE FOI MELHORADO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ NARRAÇÃO SENSUAL E HUMANA
   • Voz Microsoft Neural com tom mais grave e expressivo
   • Estilo "Cheerful" para maior carisma
   • Velocidade ajustada para criar suspense (0.85-0.90)
   • Narração em PRIMEIRA PESSOA (como se Yuna estivesse vivendo a história)

✅ EXPRESSÕES FACIAIS DINÂMICAS
   • Boas-vindas: Expressão "happy" (sorriso sedutor)
   • Teasers: Expressão "surprise" (intrigante)
   • Episódios: Expressão "happy" (envolvida)
   • Animação com driver "lively" para movimentos corporais fluidos

✅ INTERAÇÃO DOS PERSONAGENS
   • Yuna agora narra com emoção e expressividade
   • Movimentos faciais sincronizados com a voz
   • Gestos corporais mais realistas
   • Cada episódio é uma experiência imersiva

🎬 COMO USAR O BOT MELHORADO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INICIAR O BOT
    npm install
    npm run build
    npm run start

2️⃣  CONFIGURAR VARIÁVEIS DE AMBIENTE (.env)
    TELEGRAM_BOT_TOKEN=seu_token_aqui
    TELEGRAM_ADMIN_ID=seu_id_aqui
    DID_API_KEY=sua_chave_did_aqui
    PORT=3000

3️⃣  FLUXO DO USUÁRIO
    
    /start
    ↓
    Yuna aparece com vídeo de boas-vindas (expressão happy)
    ↓
    Menu principal
    ↓
    Escolher dorama
    ↓
    Escolher episódio
    ↓
    Yuna narra com expressão e animação dinâmica
    ↓
    Vídeo com qualidade HD (VIP) ou Standard (grátis)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎙️ CARACTERÍSTICAS DA VOZ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Provedora: Microsoft Azure Neural Voice
• Voz Feminina: pt-BR-ThalitaMultilingualNeural (Yuna)
• Voz Masculina: pt-BR-AntonioNeural (Galã)
• Estilo: Cheerful (expressivo e caloroso)
• Tom: -5% (mais grave e sensual)
• Velocidade: 0.85-0.90 (deliberada e envolvente)
• Sincronização: D-ID Lip-Sync em tempo real
